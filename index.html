SQL — 03
Mwendo Coffee — Supply Chain Analytics
End-to-end PostgreSQL analytics platform modelling a Kenyan direct-trade coffee supply chain, from smallholder cherry delivery through milling, export shipment, and farmer payout. Ten relational tables in an isolated schema, with full foreign-key and CHECK constraints, indexed join columns, and deterministic SQL-native seeding. Nineteen analytical queries build the picture across three layers: multi-table joins and conditional aggregation, window functions for running totals, rolling averages, rankings and Pareto concentration, then recursive CTEs for calendar spines, gaps-and-islands streak detection, and cohort retention. Includes a Python orchestrator that rebuilds the database and exports every result set as CSV.
PostgreSQL Window Functions Recursive CTEs Cohort Analysis
